OVERRUN — an original wave-survival tactical FPS on three.js 0.187.0: seeded deterministic bot waves route through an arena of cover rings, hitscan gunplay with recoil, spread and headshot multipliers, a full HUD, WebAudio-synthesized sound, and fixed-step simulation kept apart from rendering. No build step; everything runs from static ES modules.

## Run it

```sh
node serve.ts
```
